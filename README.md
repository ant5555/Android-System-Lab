  # Android System Lab                                                                                                                           
                                                                                                                                                 
  Android 시스템 주요 개념을 직접 구현하며 익히는 학습 레포입니다.                                                                               
                                                                                                                                               
  ## 모듈                                                                                                                                        

  ### stateflow-sample                                                                                                                           
  - StateFlow를 이용한 ViewModel → UI 상태 관리 흐름 학습                                                                                          
                                                                                                                                                 
  ### room-sample                                                                                                                                
  - Room DB 기본 CRUD, DAO 작성, ViewModel 연동 실습
  - 연락처 목록 추가/삭제/정렬

  ### paging-sample
  - Paging3 라이브러리를 직접 구현한 커스텀 Paginator와 비교하며 학습

  ### paging-caching-sample
  - Paging3 + Room을 RemoteMediator로 연결해 오프라인 캐싱 구현
  - Rick and Morty API 사용
  - Hilt로 의존성 주입

  ## 기술 스택
  - Kotlin, Jetpack Compose
  - Hilt, Room, Paging3
  - Retrofit, Moshi
  - StateFlow, ViewModel

  ## 목적
  완성된 프로젝트가 아닌 개념 학습용 샘플 코드입니다.
